SO-101 모터 ID·캘리브레이션 수업

현재 단계의 버튼을 눌러 Codex 프롬프트 또는 PowerShell 명령어를 복사하세요.

수업 정보 입력

포트 번호는 예시입니다. 먼저 2단계에서 실제 포트를 확인한 뒤 수정하세요.
Codex 시작포트 확인리더 ID팔로워 ID팔로워 캘리브레이션리더 캘리브레이션오류 진단
시작

Codex에게 수업 규칙 알려주기

새 대화를 열 때 한 번만 넣습니다.


    
1단계
환경 확인
가상환경을 직접 활성화하지 않아도 .venv 안의 실행 파일을 사용할 수 있습니다.
정상
Python 버전과 LeRobot 패키지 정보가 출력됨
확인
.venv\Scripts\python.exe가 실제로 존재하는가?

    
2단계
COM 포트 확인
USB-Enhanced-SERIAL CH343가 SO-101 제어 보드입니다. Bluetooth 포트는 선택하지 않습니다.
정상
CH343 장치와 COM 번호가 출력됨
구별법
한 팔을 뺐다가 다시 조회해 사라졌다 나타나는 포트를 기록

    
3단계
리더암 모터 ID 1~6 지정
ID를 지정할 대상 모터 한 개만 제어 보드에 연결합니다.
순서
1번 모터 연결 → 안내 완료 → 전원 OFF → 다음 모터
금지
여러 모터를 연결한 채 같은 ID를 쓰지 않기

    
4단계
팔로워암 모터 ID 1~6 지정
리더암은 분리하고 팔로워암만 연결합니다.
완료 기준
ID 1, 2, 3, 4, 5, 6을 각각 한 번씩 지정
기록
모터 라벨과 실제 관절 위치를 함께 확인

    
5단계
모터 6개 인식 확인
이 단계에서는 로봇을 움직이지 않고 통신만 확인합니다.
정상
Expected와 Found에 1~6이 모두 표시됨
Missing ID
해당 모터의 케이블·ID·전원을 다시 확인

    
6단계
팔로워암 캘리브레이션
팔을 안정적인 중간 자세에 놓고, 안내가 시작되면 관절을 하나씩 천천히 움직입니다.
정상
Calibration saved to ...json
주의
기구 끝에서 억지로 밀거나 0/4095 경계를 반복해서 넘기지 않기

    
7단계
리더암 캘리브레이션
팔로워와 같은 방식이지만 --teleop 옵션을 사용합니다.
정상
teleoperators 폴더에 calibration JSON 저장
다시 실행
기존 파일 질문에서 재측정하려면 c 입력

    
문제 해결
오류 메시지를 Codex에 전달
Traceback의 마지막 20~30줄과 실행 명령어를 함께 전달합니다.

  

  
수업 범위: 연결 확인 → 모터 ID → 모터 인식 → 캘리브레이션. AI 학습·카메라·데이터 수집은 진행하지 않습니다.
