SO-101 처음 설치부터 캘리브레이션까지

아무것도 설치되지 않은 Windows 노트북용 수업 페이지

먼저 확인

인터넷과 Microsoft Store를 사용할 수 있어야 합니다. 무료 계정은 Codex 사용량 제한이 있을 수 있습니다.

COM10과 COM11은 예시입니다. 포트 확인 단계가 끝난 뒤 실제 번호로 바꾸세요.

0단계

ChatGPT 데스크톱 앱 설치

공식 다운로드 페이지에서 Windows 앱을 설치합니다.

공식 다운로드 페이지 열기

  
1단계
무료 계정 로그인 후 Codex 선택
앱을 열어 ChatGPT 계정으로 로그인하고 왼쪽 위 메뉴에서 Codex를 선택합니다.
Codex 메뉴가 보이지 않으면 수업을 시작하기 전에 교사에게 알리세요.

  
2단계
배포 ZIP 압축 풀기
ZIP 안에서 실행하지 말고 마우스 오른쪽 버튼 → 모두 압축 풀기를 사용합니다. 압축을 푼 폴더의 주소 표시줄에 powershell을 입력해 PowerShell을 엽니다.

  
3단계 · 권장
자동 설치 스크립트 실행
Python 3.12, 프로젝트 폴더, 가상환경, LeRobot 패키지를 설치합니다.
정상
마지막에 SETUP COMPLETE 표시
Python 설치 후 중단
PowerShell을 닫고 같은 폴더에서 다시 실행

  
4단계 · 수동 설치
스크립트가 안 될 때 Python 3.12 설치

  
5단계 · 수동 설치
가상환경과 LeRobot 설치
다운로드 시간이 걸릴 수 있습니다. 설치 중 창을 닫지 않습니다.

  
6단계
설치 확인
정상
Python 3.12와 lerobot 정보 출력
오류
오류 진단 프롬프트에 마지막 20~30줄 전달

  
7단계
안전 확인
모터 ID 지정 시 대상 모터 한 개만 연결합니다. 갑자기 움직이면 즉시 전원을 끕니다.
전원 전압, USB, 3핀 케이블, 관절 간섭, 전원 스위치 위치를 확인합니다.

  
8단계
COM 포트 확인
SO-101 포트: USB-Enhanced-SERIAL CH343(COM번호)

  
9단계
리더암 모터 ID 지정

  
10단계
팔로워암 모터 ID 지정

  
11단계
모터 1~6 인식 확인
캘리브레이션 연결 과정에서 Found motor list에 ID 1~6이 모두 표시되는지 확인합니다. 빠진 ID가 있으면 진행하지 않습니다.

  
12단계
팔로워암 캘리브레이션

  
13단계
리더암 캘리브레이션

  
오류
