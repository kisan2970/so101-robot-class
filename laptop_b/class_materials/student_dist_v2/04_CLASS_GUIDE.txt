SO-101 처음 설치부터 캘리브레이션까지

수업 전 교사 확인
- 모든 노트북에서 인터넷과 Microsoft Store를 사용할 수 있는지 확인합니다.
- 학생이 ChatGPT 계정을 만들고 로그인할 수 있는지 확인합니다.
- ChatGPT 데스크톱 앱에서 Codex 메뉴가 보이는지 확인합니다.
- 무료 계정은 사용량 제한이 있으므로 같은 질문을 반복하지 않습니다.
- 로봇팔 전원 어댑터 전압과 USB 케이블을 확인합니다.

학생 시작 순서
1. ZIP 파일을 다운로드하고 '모두 압축 풀기'를 누릅니다.
2. https://chatgpt.com/download/ 에서 Windows용 ChatGPT 앱을 설치합니다.
3. 무료 ChatGPT 계정으로 로그인하고 왼쪽 위에서 Codex를 선택합니다.
4. SO101_수업_시작_처음설치.html을 엽니다.
5. HTML의 안내에 따라 SO101_처음설치.ps1을 실행합니다.
6. SETUP COMPLETE가 나오면 COM 포트 확인으로 넘어갑니다.
7. 리더·팔로워 모터 ID를 지정한 뒤 캘리브레이션합니다.

중요
- Python 설치 후 인식되지 않으면 PowerShell을 완전히 닫고 다시 엽니다.
- 프로젝트 폴더는 자동으로 Windows 문서 폴더 아래 lerobot-so101에 생성됩니다.
- COM10과 COM11은 예시일 뿐입니다. 실제 CH343 포트를 확인해야 합니다.
- 모터 ID 지정 시 대상 모터 한 개만 제어 보드에 연결합니다.
- Overload, 큰 움직임, 관절 걸림이 있으면 즉시 전원을 끕니다.
