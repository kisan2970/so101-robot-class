SO-101 수업 시작

1. ZIP 파일을 바탕 화면에 복사합니다.
2. ZIP을 마우스 오른쪽 버튼으로 눌러 "모두 압축 풀기"를 선택합니다.
3. 압축을 푼 폴더에서 01_START_HERE.html을 엽니다.
4. 설치 단계에서 02_INSTALL_LEROBOT.ps1을 사용합니다.

중요
- ZIP 안에서 파일을 바로 실행하지 마세요. 먼저 압축을 풀어야 합니다.
- 파일 확장자가 숨겨져 있어도 02_INSTALL_LEROBOT이라는 이름으로 보일 수 있습니다.
- Windows가 실행을 막으면 파일을 마우스 오른쪽 버튼으로 누르고 속성에서 "차단 해제"를 선택합니다.
- 로봇 전원은 모터 연결과 ID 확인이 끝난 뒤에 켭니다.

포함 파일
- 01_START_HERE.html: 학생용 시작 화면
- 02_INSTALL_LEROBOT.ps1: Python, 가상환경, LeRobot 설치
- 03_CODEX_PROMPT.txt: Codex에 붙여 넣을 안내문
- 04_CLASS_GUIDE.txt: 수업 진행 안내
- TEACHER_SLIDES.pptx: 교사용 설명 자료
