01

시작 전

전원 스위치와 작업 공간부터 확인합니다

전원

이상할 때 바로 끌 수 있도록 손이 닿는 곳에 둡니다.

공간

팔이 움직이는 범위에서 사람과 물건을 치웁니다.

관절

기구적으로 걸리는 곳까지 억지로 밀지 않습니다.

02

환경 확인

Python과 Git이 준비되어 있는지 확인합니다

PowerShell을 열고 아래 명령을 한 줄씩 실행합니다. 버전 번호가 보이면 준비된 상태입니다.

py --version
python --version
git --version
03

프로그램 설치

전용 작업 공간을 만들고 LeRobot을 설치합니다

가상환경은 이 실습만을 위한 독립된 Python 공간입니다. Activate 없이 실행 파일을 직접 사용합니다.

mkdir "$env:USERPROFILE\Documents\lerobot-so101"
cd "$env:USERPROFILE\Documents\lerobot-so101"
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\pip.exe install "lerobot[feetech]" opencv-python pyserial
문서 폴더가 OneDrive에 있다면 경로를 $env:USERPROFILE\OneDrive\문서\lerobot-so101로 바꿉니다.
04

USB 연결

리더암과 팔로워암의 COM 포트를 찾습니다

두 팔을 USB로 연결하고 실행합니다. Bluetooth 포트는 무시하고 USB-Enhanced-SERIAL CH343을 찾습니다.

.\.venv\Scripts\python.exe -m serial.tools.list_ports -v

한쪽 USB를 뺐을 때 사라지는 번호를 보면 어떤 팔인지 구분할 수 있습니다.

05

모터 설정

각 관절에 ID 1부터 6까지 이름표를 붙입니다

1어깨 좌우2어깨 위아래3팔꿈치4손목 굽힘5손목 회전6집게
설정할 모터 하나만 연결합니다.

같은 ID의 모터를 여러 개 연결한 채 변경하면 충돌할 수 있습니다.

Leader arm

.\.venv\Scripts\lerobot-setup-motors.exe --teleop.type=so101_leader --teleop.port={{LEADER}} --teleop.id=my_so101_leader

Follower arm

.\.venv\Scripts\lerobot-setup-motors.exe --robot.type=so101_follower --robot.port={{FOLLOWER}} --robot.id=my_so101_follower
06

움직임 기준

두 팔의 중간 위치와 사용 범위를 기록합니다

베이스 정면어깨 중간팔꿈치 약 90°집게 반쯤 열기

Follower calibration

.\.venv\Scripts\lerobot-calibrate.exe --robot.type=so101_follower --robot.port={{FOLLOWER}} --robot.id=my_so101_follower

Leader calibration

.\.venv\Scripts\lerobot-calibrate.exe --teleop.type=so101_leader --teleop.port={{LEADER}} --teleop.id=my_so101_leader
새로 캘리브레이션할 때 질문이 나오면 c를 입력합니다. wrist_roll은 기록표에서 제외될 수 있으며 정상입니다.
07

첫 동작

10초 동안 안전 제한 teleoperation을 시험합니다

처음에는 이동량과 속도를 제한합니다. 갑자기 튀거나 이상한 소리가 나면 즉시 전원을 끕니다.

.\.venv\Scripts\lerobot-teleoperate.exe --robot.type=so101_follower --robot.port={{FOLLOWER}} --robot.id=my_so101_follower --robot.max_relative_target=3 --teleop.type=so101_leader --teleop.port={{LEADER}} --teleop.id=my_so101_leader --fps=15 --teleop_time_s=10
  • 관절 방향이 맞는가?
  • 1~6번 모터가 모두 움직이는가?
  • 과부하나 USB 끊김이 없는가?
08

정상 운전

안전 테스트가 끝났다면 일반 teleoperation을 실행합니다

.\.venv\Scripts\lerobot-teleoperate.exe --robot.type=so101_follower --robot.port={{FOLLOWER}} --robot.id=my_so101_follower --teleop.type=so101_leader --teleop.port={{LEADER}} --teleop.id=my_so101_leader
Teleoperation 준비 완료

이 단계까지 안정적으로 작동하면 연결, 모터 설정, 캘리브레이션이 완료된 것입니다.

TROUBLESHOOTING

자주 나오는 오류

Could not connect on port

COM 번호, USB 인식, FD 프로그램 점유 여부를 확인합니다.

Missing motor IDs

모터 ID 중복, 케이블 연결, 모터 전원을 확인합니다.

Incorrect status packet

중복 ID, 케이블 접촉, 전원 불안정을 확인합니다.

ClearCommError failed / Access denied

실행 중 USB가 끊겼을 가능성이 큽니다. 전원을 끄고 USB를 다시 연결합니다.

시작하자마자 크게 움직임

즉시 전원을 끄고 leader/follower 포트와 캘리브레이션을 다시 확인합니다.

CODEX TEACHING PROMPT

다른 Codex 계정에 붙여넣기

학생이 결과를 보내면 한 단계씩 다음 명령을 안내하도록 설정한 프롬프트입니다.

너는 초보 학생에게 Hugging Face LeRobot 기반 SO-101 로봇팔을 가르치는 실습 조교다.

학생은 Python, PowerShell, COM 포트, 모터 ID를 잘 모를 수 있다. 어려운 코드 원리보다 지금 무엇을 확인하고 무엇을 실행해야 하는지 쉽고 짧게 설명해라.

최종 목표는 Windows 컴퓨터에서 SO-101 leader arm과 follower arm을 연결하고, 모터 ID 설정, 캘리브레이션, teleoperation까지 안전하게 성공하는 것이다. AI 학습, 카메라, 데이터 녹화는 진행하지 마라.

지도 규칙:
- 한 번에 모든 단계를 설명하지 말고 현재 단계의 명령 1~2개만 제공한다.
- 학생이 출력 결과를 보내면 분석한 뒤 다음 단계로 넘어간다.
- Windows PowerShell에서 복사 가능한 명령어를 코드블록으로 제공한다.
- 여러 줄 백틱 오류를 피하기 위해 가능하면 한 줄 명령을 사용한다.
- conda 대신 Python venv를 사용한다.
- Activate가 실패해도 .venv\Scripts 안의 실행 파일을 직접 사용한다.
- COM 번호를 추측하지 말고 serial.tools.list_ports로 다시 찾게 한다.
- Bluetooth COM과 USB-Enhanced-SERIAL CH343을 구분한다.
- 모터 ID 설정은 안내된 모터 한 개만 연결한 상태에서 진행한다.
- teleoperation은 처음에 max_relative_target=3, fps=15, 10초 제한으로 시험한다.
- 갑작스러운 움직임, 과부하, USB 끊김이 생기면 즉시 전원을 끄게 한다.

모터 ID:
1 shoulder_pan, 2 shoulder_lift, 3 elbow_flex, 4 wrist_flex, 5 wrist_roll, 6 gripper
